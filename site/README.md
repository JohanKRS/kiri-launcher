# Kiri website

The project site, meant for https://kiri.johankrs.com/: plain HTML, CSS and JavaScript, with no build
step and nothing to install on the server. All paths are relative, so it works from any folder or
subdomain.

## Publishing

Copy everything in this folder (this README too, if you like) to the web server. That's it.

## Editing

- **Text:** the English text is in `index.html` and `privacy.html`. The Portuguese and Spanish
  versions are in `assets/i18n.js`, under the same keys as the `data-i18n` attributes. When you
  change an English text, change both translations too.
- **Language:** the page picks `?lang=pt` / `?lang=es` from the address, then the visitor's last
  choice, then the browser's language, and falls back to English (`assets/boot.js`).
- **Glass and wallpaper:** the page behaves like a Kiri home screen. The wallpaper is drawn by
  `assets/site.js` from Kiri's own TV wallpapers (Aurora, Oceano, Grafite, Pôr do sol, in
  `ui/tv/TvArt.kt`), with its lights drifting and threads of mist floating across. Everything on it
  is glass in one of Kiri's three glasses (`ui/theme/KiriGlass.kt`). Visitors can pick both, and
  turn the motion off; the page remembers it. With "reduce motion" on, nothing moves.
- **Screenshots, logo, icons and the link preview** are generated by `scripts/make_site_assets.py`
  from the Play Store pictures in `fastlane/metadata/android`, the icon drawing and the Figtree
  font. Run it again after changing any of those. Spanish uses the English screenshots.
- **The address** appears only in the `<head>` of the two pages (the canonical link, the language
  links and the `og:` tags for link previews, which need a full address). If the site moves, change
  it there.
- **The privacy policy** (`privacy.html`) is the site version of `docs/privacidade.md`. Keep the two
  saying the same thing.
